# Laboratoire du contrefactuel

Site compagnon du cours « Comment savoir si une politique marche ? Le contrefactuel, ou l'art de comparer avec ce qui ne s'est pas produit » (fil rouge : les Casques bleus ramènent-ils la paix ?).

- **Cours complet, avec les diapositives** : https://roddesbordes-dev.github.io/laboratoire-contrefactuel/
- **Simulations seules** : https://roddesbordes-dev.github.io/laboratoire-contrefactuel/simulateur.html

Toutes les données des simulations sont fictives : on fixe soi-même le vrai effet, puis on regarde si chaque méthode le retrouve.

Rodolphe Desbordes, SKEMA Centre for Global Risks (SCGR), SKEMA Business School.
